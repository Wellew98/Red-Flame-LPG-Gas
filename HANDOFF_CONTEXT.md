## Lessons learned (worth knowing for next session)

- **GBP description policy** rejects phone numbers, URLs, CTAs ("Call X", "for a quote"), promotional language. Wellew's first description draft rejected for both phone + CTA. Reapply: descriptions must be informational only.
- **GBP services are display, not ranking.** Don't over-engineer for SEO surface — they affect listing UX, not local-pack rank. Categories, NAP, reviews, descriptions, photos drive rank. Two well-crafted services beat six mediocre ones.
- **Pattern: Wellew's pushback is usually correct.** Twice this session (allow-all bots; 4 services not 6) Wellew applied empirical/credibility intuition that overrode my SEO-density bias. When a recommendation feels like "more, more, more," default to less and let Wellew expand later.
- **Cloudflare's "AI Audit" overrides repo `robots.txt`.** Two toggles in zone → AI Crawl Control. Both currently OFF as of 2026-04-28.
- **Don't trust large Edit operations on long files without a tail-integrity check** (still relevant from prior session).
- **Cloudflare Pages deploys via GitHub sync.** Local file edits don't go live until pushed.
- **Postcode 7925 is the street code for Woodstock; 7915 is PO Box only.** Verified via Google. Worth knowing for any future address citations.
- **`/woodstock` (no .html) and `/woodstock.html` both serve content** because Cloudflare Pages auto-resolves clean URLs. Always inspect the `.html` version in GSC URL Inspection — that's the canonical, the one in the sitemap.
